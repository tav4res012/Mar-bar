# Maré Bar

Site de apresentação da **Maré Bar**, uma coquetelaria artesanal especializada em bebidas para eventos. A página inicial apresenta o cardápio de forma organizada por categorias, enquanto a página de agendamento permite preencher os dados básicos para solicitar um evento.

## Páginas

- **Início (`index.html`)**: apresenta shots, drinks alcoólicos e opções sem álcool, além de informações de contato e um botão para acessar o agendamento.
- **Agendamento (`agendamento.html`)**: formulário para informar nome, data de nascimento, endereço, data e horário do evento. O botão de envio é habilitado quando os campos estão preenchidos.

## Tecnologias

- HTML5
- CSS3, com estilos responsivos para celulares
- JavaScript para validação básica do formulário
- Font Awesome e Google Fonts

## Como visualizar

Abra o arquivo `index.html` em um navegador. Os arquivos HTML e CSS devem permanecer na mesma pasta para que os estilos e a navegação entre as páginas funcionem.

> Atualmente, o formulário exibe uma confirmação no navegador, mas não envia nem armazena os dados em um servidor.
